Benachrichtigungen

    Server und Agent-Updates

    Neue Agent-Versionen kommen als signierte GitHub-Releases. Agenten prüfen die Signatur selbst und aktualisieren sich nur auf Knopfdruck.

    Agent installieren

    Befehl auf dem Host ausführen, das Token wird abgefragt. Das Skript lädt den neuesten Agenten, prüft die Prüfsumme und übernimmt das Server-Zertifikat nur, wenn der Fingerabdruck stimmt. Der Host muss den Server unter dieser Adresse erreichen.
